# Pull Request: добавить локальный цикл обезличивания и восстановления данных

## Предлагаемый заголовок

`feat: добавить анонимайзер документов с картой замен и деанонимизацией`

## Краткое описание

Добавляет в существующее приложение страницу `/anonymizer`, локальный OCR PDF-сканов и опциональный защищённый API-адаптер Qwen. Серверное хранилище документов и карт не создаётся.

Весь цикл выполняется в браузере: загрузка документа или вставка текста, извлечение, поиск и ручная проверка сущностей, замена стабильными токенами, экспорт безопасного текста и карты, а затем обратное восстановление данных после работы во внешнем ИИ.

## Что входит

- ввод через TXT/DOCX/PDF до 10 МБ или вставку текста;
- локальное извлечение текста без отправки документа на сервер;
- локальный Tesseract.js OCR для PDF-страниц без текстового слоя;
- Qwen как автоматически подключаемый детектор пропусков с версионным системным промптом и строгим JSON;
- читаемые токены вида `[[ФИО_001]]`;
- объединение полной формы ФИО и формы с инициалами в одну сущность;
- центральная редактируемая карта «исходное значение → токен»;
- количество вхождений, варианты написания, смена категории и решения;
- ручные операции объединения и разделения сущностей;
- добавление пропуска из выделенного фрагмента исходного/безопасного текста;
- контроль целостности с диагностикой, пересчётом и осознанным продолжением;
- сохранение текущей сессии в рамках вкладки и явное постоянное локальное сохранение;
- экспорт безопасного TXT, карты JSON и ZIP-комплекта;
- шаг деанонимизации по текущей, сохранённой или загруженной карте;
- диагностика неизвестных и неиспользованных токенов;
- автоматические тесты ядра правил.

## Что не входит

- отдельная загрузка изображений и рукописный OCR;
- сохранение исходного форматирования DOCX/PDF;
- серверное хранение документов или карт;
- автоматическая отправка текста во внешние ИИ-сервисы;
- пакетная обработка.

## Данные и информационная безопасность

- исходный текст и карта не передаются на backend;
- текущая сессия автоматически хранится только до закрытия вкладки;
- постоянная локальная сессия создаётся пользователем после предупреждения;
- карта JSON и ZIP содержат исходные чувствительные значения и скачиваются после отдельного предупреждения;
- неизвестные токены при восстановлении сохраняются без изменений;
- автоматическая обработка не заменяет проверку человеком.

## Проверки

Автоматические:

```bash
npm test
```

Покрыты: устойчивые токены, алиасы ФИО, однофамильцы, ручные сущности, объединение, номера договоров, ложные срабатывания на НПА, контакты и идентификаторы, целостность, карта v2 и деанонимизация.

Ручной smoke-test:

1. Вставить синтетический текст с полным ФИО и инициалами.
2. Убедиться, что обе формы имеют один токен и два вхождения в одной строке карты.
3. Подтвердить организацию и добавить пропущенный фрагмент вручную.
4. Разделить и снова объединить варианты ФИО.
5. Подтвердить проверку и скачать результаты.
6. Перейти на шаг 4, вставить текст с токенами и восстановить текущей картой.
7. Проверить сообщение для неизвестного токена.

## Безопасный выпуск

Изменение не добавляет таблиц БД, API или фоновых процессов. Рекомендуемый порядок: PR → preview-окружение → ручной smoke-test → merge в `main`. Откат ограничивается маршрутом, ссылками навигации и статическими файлами анонимайзера.
